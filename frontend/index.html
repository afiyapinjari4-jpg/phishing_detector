About PhishGuard Project

Machine Learning Major Project — Phishing URL & Malicious Link Detection

Project Defense Summary

PhishGuard is an autonomous URL cybersecurity analyzer built to detect zero-day phishing links using tabular feature engineering and an ensemble Random Forest classifier. By parsing 17 statistical, structural, and lexical properties directly from raw URL strings, the model flags malicious campaigns without costly external threat subscriptions or content web-scraping.

Machine Learning Random Forest (100 Trees)
Backend Framework FastAPI / Uvicorn
Dataset Benchmark Kaggle Malicious URLs (30k balanced)
Model Accuracy 94.27% Verified Testing Score
